# VS Code Keyboard Shortcuts for Windows

| Action | Shortcut | Description |
|---|---|---|
| Open Keyboard Shortcuts | `Ctrl+K Ctrl+S` | Open the keyboard shortcut editor to view or customize key bindings. |
| Open Command Palette | `Ctrl+Shift+P` | Search and run VS Code commands by name. |
| Open File | `Ctrl+O` | Open an existing file from disk. |
| Save File | `Ctrl+S` | Save the current file. |
| Close Editor | `Ctrl+W` | Close the current editor tab. |
| Split Editor | `Ctrl+\` | Split the editor into two side-by-side views. |
| Toggle Terminal | `Ctrl+` ` (backtick)` | Show or hide the integrated terminal. |
| Find | `Ctrl+F` | Search within the current file. |
| Replace | `Ctrl+H` | Search and replace text in the current file. |
| Go to Line | `Ctrl+G` | Jump to a specific line number in the file. |
| Comment Line | `Ctrl+/` | Toggle line comment for the selected line(s). |
| Format Document | `Shift+Alt+F` | Format the current file using the default formatter. |
| Toggle Sidebar | `Ctrl+B` | Show or hide the activity sidebar. |
| Open Explorer | `Ctrl+Shift+E` | Focus the file explorer panel. |
| Open Search | `Ctrl+Shift+F` | Open the global search panel across the workspace. |
| Open Source Control | `Ctrl+Shift+G` | Open the source control view. |
| Open Extensions | `Ctrl+Shift+X` | Open the extensions marketplace and installed extensions list. |
| Dublicate | `ALT+Shift+downarrow | Dublictaes the line
